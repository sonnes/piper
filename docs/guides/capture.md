# Capture Notes

The capture panel is a floating window for short notes. It stays above other apps, on every Space. Piper saves each note in a local database. See [Local storage](../concepts/storage.md) for the details.

Open the panel with Command-1, the menu bar icon, or the New Capture button in the main window toolbar. The panel and the main window take turns. When one opens, the other leaves the screen. Neither closes, so a draft stays as it is.

To move the panel, drag an empty part of it. To resize the panel, drag an edge or a corner. Piper keeps the size and the position for the next launch.

## Read The Panel

The panel shows one list. The list starts with the five latest clipboard texts. Then it shows each section under its own header. A section with no notes shows one "No notes" row.

The header has one tab for each section, with its count of open notes. Select a tab to scroll the list to that section. The selected tab is also the section for new notes. Its header shows in the accent color.

The Clipboard tab sits at the left of the section tabs. It shows the full clipboard history. See [Save a clipboard text](#save-a-clipboard-text).

The + tab creates a section. The More Actions menu has Capture Clipboard, Capture To, New Section, Open Main Window, Settings, Undo Last Change, and Close Capture.

If Accessibility access is off, a tip at the top of the list has an Enable button. Select the close button to hide the tip. Settings > Capture keeps the permanent control.

## Save A Note

1. Open the capture panel with Command-1.
2. Type or paste text into the composer at the bottom.
3. Press Return.

Shift-Return adds a new line. The note goes to the selected section, which is Inbox at first. The composer placeholder names that section. The composer keeps the keyboard focus after each save.

If you close the panel with Escape, Piper keeps the unfinished text in the composer.

## Save A Clipboard Text

Piper shows the texts that you copy while it runs. These texts are not saved.

1. Copy text in any app.
2. Open the capture panel with Command-1.
3. Move the pointer over a clipboard row.
4. Select Keep.

Keep always saves to Inbox, even when another section is selected. The row goes away after a successful save.

Home also has a Capture Clipboard action. It saves the current clipboard text to the active capture section.

1. Type `>` in Home search.
2. Select Capture Clipboard.

If a sidebar folder has Claude Code skills, the row also shows Send to <folder>. See [Send notes to Claude](claude.md).

Double-click a row to paste the text into the app in front. The row context menu has Paste and Keep in Inbox. Paste needs Accessibility access. Without it, Piper copies the text, and you paste it with Command-V.

The Clipboard tab groups the full history by day. Each row shows the text, the app that was in front when you copied it, and the time. Clear History at the end of the list removes every unsaved text.

Clipboard texts obey these rules:

- Piper keeps the 50 latest texts for 7 days. The history survives a restart.
- The same text shows once. A new copy of that text moves it to the top.
- Text that is already a saved note does not show.
- Piper skips images, text larger than 500 KB, and items that the source app marks concealed, transient, or autogenerated.
- If a save fails, the row stays.
- If a text looks like source code, its row shows the first line of the code in a monospaced font. Piper treats a text as code when it has two or more lines and at least half of them are indented or have a bracket at the start or end.

## Capture A Selection

Before you start, allow Accessibility access. See [Install Piper](install.md#allow-selection-capture).

1. Select text in another app.
2. Press and release Shift twice, within 0.35 seconds.

To use Control-Option-Space instead, change Shortcut in Settings > Capture. If another app holds Control-Option-Space, Piper reports the conflict.

Piper reads the selection directly. It does not simulate Copy, and it does not change the clipboard or the focus. The note records the source app, and its row shows "From" and the app name. If the source app exposes an HTTP or HTTPS document URL, the note records it too.

A secure text field or an empty selection creates no note. A small toast confirms each capture for three seconds.

If an app does not expose its selection, use the clipboard:

1. Copy the text in the source app.
2. Select Capture Clipboard in the menu bar icon, or in the More Actions menu of the panel.

## Organize Notes

Sections group notes.

- To create a section, select the + tab. In the main window, select New Section at the bottom of the sidebar.
- To change the section for new notes, select its tab, or press Command-K.
- To create or select a section from the composer, type `# Research` alone and press Return.
- To run a folder skill, type `/` and the skill name. See [Send notes to Claude](claude.md#run-a-skill-from-the-composer).
- To find notes, press Command-F. Search matches note text in all sections and in the clipboard. To end the search, select Cancel or press Escape.

Section names have 1 to 80 characters and ignore case.

## Act On Several Notes

1. Click a note.
2. Command-click more notes, or Shift-click to select a range.
3. Select an action in the selection bar.

| Action | Result |
| --- | --- |
| Merge | Joins the notes with blank lines between them |
| Move | Moves the notes to another section |
| Copy | Copies the text of the notes |
| Send | Runs the default Claude skill on each note. See [Send notes to Claude](claude.md). |
| Delete | Deletes the notes, with no confirmation |

Command-Shift-C copies the notes as a numbered list. The note context menu also has Copy as List, Mark as Done, Edit, and Open in Browser.

Undo reverses the last note change. Piper keeps one undo step, and a restart clears it.

## Edit A Note

- To edit the selected note in the panel, press Return.
- To open the note in a separate editor window, press Command-Return.
- To write the edit, select Save.

In the main window, the detail pane edits the selected note in place. Piper saves the change shortly after you stop typing.

The circle on each row marks the note as done. Space marks the selected notes as done, or opens them again.

If you close a changed editor or quit Piper, Piper asks you to Save, Discard, or Cancel. A failed save keeps the draft.

For all shortcuts, see [Keyboard shortcuts](shortcuts.md).
