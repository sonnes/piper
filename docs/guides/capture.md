# Capture Notes

The capture panel is a floating window for short notes. It stays above other apps, on every Space. Piper saves each note in a local database. See [Local storage](../concepts/storage.md) for the details.

Open the panel with Command-1, the menu bar icon, or the capture button in the Wiki toolbar. The panel and the Wiki window take turns. When one opens, the other leaves the screen. Neither closes, so a draft stays as it is.

## Save A Note

1. Open the capture panel with Command-1.
2. Type or paste text into the composer at the bottom.
3. Press Return.

Shift-Return adds a new line. The note goes to the active section, which is Inbox at first. The composer keeps the keyboard focus after each save.

If you close the panel with Escape, Piper keeps the unfinished text in the composer.

## Save A Clipboard Entry

Piper shows recent clipboard text as muted cards under Clipboard, above your saved notes. These cards are not saved.

1. Copy text in any app while Piper runs.
2. Open the capture panel with Command-1.
3. Command-click the card to save it as a note.

A plain click pastes the card text into the app that was in front. This paste needs Accessibility access. Without it, Piper copies the text and asks you to press Command-V.

The card context menu also has Paste and Save To. Save To saves the card into the active section.

Clipboard cards follow these rules:

- Piper keeps the ten most recent text entries, in memory only.
- The same text shows once.
- Text that is already a saved note does not show.
- Piper skips images, text larger than 500 KB, and items that the source app marks concealed, transient, or autogenerated.
- If a save fails, the card stays.

## Capture A Selection

Before you start, allow Accessibility access. See [Install Piper](install.md#allow-selection-capture).

1. Select text in another app.
2. Press and release Shift twice, within 0.35 seconds.

To use Control-Option-Space instead, change Shortcut in Settings > Capture. If another app holds Control-Option-Space, Piper reports the conflict.

Piper reads the selection directly. It does not simulate Copy, and it does not change the clipboard or the focus. The note records the source app. If the source app exposes an HTTP or HTTPS document URL, the note records it too.

A secure text field or an empty selection creates no note. A small toast confirms each capture for three seconds.

If an app does not expose its selection, use the clipboard:

1. Copy the text in the source app.
2. Select Capture Clipboard in the menu bar icon, or in the More Actions menu of the panel.

## Organize Notes

Sections group notes. The tabs in the panel header show each section with its count of open notes.

- To change the section for new notes, press Command-K.
- To create or select a section, type `# Research` alone in the composer and press Return.
- To find notes, press Command-F. Search matches note text and section names.

Section names have 1 to 80 characters and ignore case.

## Act On Several Notes

1. Click a note.
2. Command-click more notes, or Shift-click to select a range.
3. Select an action in the selection bar.

| Action | Result |
| --- | --- |
| Merge | Joins the notes with blank lines between them |
| Move | Moves the notes to another section |
| Wiki | Opens Send to Wiki. See [Export captures](export.md). |
| Copy as List | Copies numbered text and indents continuation lines |
| More Actions menu | Copy, Mark as Done / Reopen, Clear Selection, and Delete Notes |

Undo reverses the last note change. Piper keeps one undo step, and a restart clears it.

## Edit A Note

- Press Return to edit the selected note in the panel.
- Press Command-Return to open the note in a separate editor window.
- Select Save Changes to write the edit.

The circle on each card marks the note as done. Space marks the selected notes as done, or opens them again.

If you close a changed editor or quit Piper, Piper asks you to Save, Discard, or Cancel. A failed save keeps the draft.

## Change The Style

Settings > Style has two styles. Vault uses system type, tinted panes, and bordered buttons. Page uses IBM Plex Mono everywhere, flat surfaces, and text buttons. Both keep the same layout and shortcuts.

For all shortcuts, see [Keyboard shortcuts](shortcuts.md).
