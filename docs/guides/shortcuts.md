# Keyboard Shortcuts

## Everywhere

| Shortcut | Action |
| --- | --- |
| Shift, Shift | Capture the selection in another app (default) |
| Control-Option-Space | Capture the selection, if you choose it in Settings > Capture |
| Command-1 | Show the capture panel |
| Command-2 | Show the file browser in the Wiki window |
| Command-0 | Show Home in the Wiki window |
| Command-comma | Open Settings |
| Command-Q | Quit Piper |

Command-S, Command-[, and Command-] act on the Wiki window even when the capture panel is in front.

## Capture Panel

These shortcuts work when the panel is in front and no sheet is open.

| Shortcut | Action |
| --- | --- |
| Return | Save the composer, or edit the selected note |
| Shift-Return | Add a new line in the composer |
| Command-Return | Save in an editor, or open the selected note in a separate window |
| Command-N | Move the focus to the composer and clear the selection |
| Command-K | Choose the section for new notes |
| Command-F | Search notes |
| Up / Down | Select the previous or next note |
| Shift-Up / Shift-Down | Add the previous or next note to the selection |
| Command-A | Select all matching notes |
| Space | Mark the selected notes as done, or open them again |
| Command-C | Copy the selected notes |
| Command-Shift-C | Copy the selected notes as a numbered list |
| Command-Shift-M | Merge the selected notes |
| Command-Z | Undo the last note change |
| Delete / Forward Delete | Delete the selected notes, with no confirmation |
| Escape | Clear the selection, then clear the search, then close the panel |
| Command-W | Close the panel |

Inside a text editor, Command-A, Command-C, Command-Z, and the arrow keys edit the text.

## Wiki Window

| Shortcut | Action |
| --- | --- |
| Command-O | Open Home and move the focus to its search field |
| Up / Down, Return | Select and open a Home search result |
| Command-S | Save the open Markdown file |
| Command-R | Scan the Wiki folder again |
| Command-[ | Go back |
| Command-] | Go forward |
| Command-Z | Undo an edit |
| Command-W | Close the window |

The Wiki window has no find command for the open file.
