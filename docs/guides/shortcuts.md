# Keyboard Shortcuts

## Everywhere

| Shortcut | Action |
| --- | --- |
| Shift, Shift | Capture the selection in another app (default). On a web page, highlight the selection, or save the page when no text is selected. While a highlight toast shows, add a note to the highlight. |
| Control-Option-Space | Capture the selection, if you choose it in Settings > Capture |
| Control-Option-W | Save the clipboard to Inbox and open a draft for the default folder, while a folder has Claude skills |
| Command-1 | Show the feed paper on Today, with the cursor in the capture field. This works from every paper. |
| Command-2 | Show the feed paper on Feeds, with Sources |
| Command-3 | Show the feed paper on Hacker News, with the top stories of Hacker News |
| Shift-Command-N | Add a feed: show Sources with the cursor in its address field |
| Command-0 | Show the feed paper and the open reader papers |
| Command-comma | Open Settings |
| Command-Q | Quit Piper |

Command-S, Command-[, and Command-] act on the file paper even when another paper has the focus.

## Today

These shortcuts work in Today on the feed paper when no sheet is open. The letter keys need a selected row and no active text field.

| Shortcut | Action |
| --- | --- |
| Return | Save the capture field, or open the selected row |
| Option-Return | Save a site or feed address in the capture field to read later, in place of opening Sources |
| Shift-Return | Add a new line in the capture field |
| Command-Return | Open the selected note in a separate editor window |
| 1, 2, 3, 4 | Show the All, Notes, Reading, or Kept lens |
| K | Keep the selected rows, or remove the mark from kept notes |
| E | Mark the selected rows as done, with Undo for 5 seconds |
| F | File the selected rows in a section, a folder, or a file |
| S | Send the selected rows with the default skill |
| M | Merge the selected notes |
| Space | Mark the selected rows as done, or open done notes again |
| Command-F | Search Today |
| Up / Down | Select the previous or next row |
| Click | Select a row. A click on the selected row opens it. |
| Click the circle | Mark a note as done |
| Command-click | Add a row to the selection, or remove it |
| Shift-click | Select a range of rows |
| Shift-Up / Shift-Down | Add the previous or next row to the selection |
| Command-A | Select all rows |
| Command-C | Copy the selected rows |
| Command-Shift-C | Copy the selected rows as a numbered list |
| Command-Shift-Return | Prepare a draft for each selected row in the default folder |
| Command-Z | Undo the last change, such as Done, Delete, File, Mark All as Read, or a note change. Press it again to undo the change before it. |
| Shift-Command-Z | Redo the change that Command-Z undid |
| Delete / Forward Delete | Delete the selected notes and clipboard texts, with Undo. Delete does nothing on an article. |
| Escape | Clear the selection, then clear the search |

When the capture field shows the skill list, Up and Down move the highlight. Tab puts the skill in the field. Return does the same, or runs a skill that takes no argument. Escape clears the command.

Inside a text editor, Command-A, Command-C, Command-Z, and the arrow keys edit the text.

In the File list, Up Arrow and Down Arrow choose a place, Return files the rows, and Escape closes the list.

## Papers

| Shortcut | Action |
| --- | --- |
| Command-N | Show Today on the feed paper, with the cursor in the capture field |
| Command-S | Save the open Markdown file at once. Piper also saves 120 ms after an edit. |
| Command-K | Open the command palette. In the editor, with text selected, make a link. |
| Command-F | Find and replace text in the open Markdown file |
| Command-R | Scan the folder and read the skills of each folder again |
| Command-[ | Go back |
| Command-] | Go forward |
| Command-Z | Undo an edit in a text field. Outside a text field, undo the last change to the notes. |
| Shift-Command-Z | Redo |
| Command-W | Close the reader paper with the focus, or the feed paper |
| Escape | Close the reader paper with the focus. On the feed paper, go from the index back to the list. |
| Command-` | Move the focus to the next paper |
| T | Put each reader paper back in its place of the cascade |
| Command-4 to Command-9 | On the feed paper, show the tab with that number at its first scope, in the order of the column |
| Left Arrow | On the feed paper, open the index of Today, Feeds, or Agents |
| Up Arrow / Down Arrow | On the index, move the cursor. In the folder tree, move the cursor through the rows that show. In a list of sessions, select the previous or next row. |
| Return / Right Arrow | On the index, show the scope at the cursor. Return in a list of sessions opens the row on a paper. |
| Right Arrow | In the folder tree, open a closed folder. On an open folder, move to its first row. |
| Left Arrow | In the folder tree, close an open folder. On another row, move to its folder. |
| Return | In the folder tree, open a file on the file paper, or open or close a folder |
| `[` / `]` | On the feed paper, show the previous or the next scope of the tab |
| Option-Command-C | Open or close the session card of the reader paper with the focus. With no reader paper open, open the detached session panel. |
| Command-K | In the Reader tab, with text selected, ask about the selected text |
| H | In the Reader tab, highlight the selected text |
| N | In the Reader tab, write a note on the selected text. Return saves the note. Escape keeps the highlight with no note. |
| Up Arrow / Down Arrow | In the Reader tab, scroll the article. On the comments of a Hacker News story, scroll the comments. |
| Page Up / Page Down | In the Reader tab, or on the comments of a Hacker News story, scroll one screen up or down |
| Option-Down Arrow / Option-Up Arrow | In the Reader tab, move to the next or the previous mark |
| Escape | In the Reader tab, close the selection bar |

## Feeds

These shortcuts work in the list of one feed. K and B also work on an article paper with the focus. See [Read feeds](feeds.md).

| Shortcut | Action |
| --- | --- |
| Space | Open the next unread article |
| K | Keep the selected article |
| B | Open the selected article in the browser |
| Shift-Command-K | Mark all articles in the list as read. File > Mark All as Read does the same. Command-Z undoes it. |

## Claude Sessions

These shortcuts work in the message field of a session.

| Shortcut | Action |
| --- | --- |
| Return | Send the message |
| Shift-Return | Add a new line |
| Up / Down | Move the highlight in the skill list or the file list |
| Tab | Put the highlighted skill or file in the message |
| Escape | Close the skill list or the file list |
