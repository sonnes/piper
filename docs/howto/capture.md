# Capture Notes

## Build And Open

1. Open a terminal in the Piper repository.
2. Run `make test`.
3. Run `make run`.
4. Use the capture panel that opens at launch.

The first build downloads pinned Yams and SwiftMarkdownEngine dependencies. Core application functions work offline.

## Build A Signed Release

Piper uses the `com.piper` bundle ID. The release target signs the app for direct download and creates a versioned DMG.

The ignored `.envrc` supplies the signing identity and App Store Connect key. Credentials remain outside the app bundle.

1. Make sure that Keychain Access contains the `Developer ID Application` certificate and its private key.
2. Run `make release` from the repository root.
3. Make sure that `notarytool` reports an `Accepted` status.
4. Save the SHA-256 checksum that the command shows.

The DMG is at `build/Piper_<version>_<architecture>.dmg`. The release target notarizes, staples, and validates this file.

On a different workstation, create an ignored `.envrc` with these variables:

```text
APPLE_TEAM_ID
APPLE_SIGNING_IDENTITY
APPLE_API_ISSUER
APPLE_API_KEY
APPLE_API_KEY_PATH
```

`APPLE_API_KEY_PATH` must identify the App Store Connect team key. Piper does not require `APPLE_PROVISIONING_PROFILE`.

## Save A Note

1. Open the capture panel with Command-1.
2. Type or paste text into the composer at the bottom.
3. Press Return.

New notes default to Inbox. Shift-Return inserts a new line. Each note appears under its section header. The composer keeps keyboard focus after each save.

Long drafts scroll inside the composer. If the text exceeds the editor height, a scrollbar appears. The editor keeps its padding during scrolling.

Escape closes the panel and preserves the unfinished draft. The rounded window measures 430 by 932 points and scales to smaller screens.

## Save A Clipboard Preview

Piper shows recent clipboard text as faded cards with dashed outlines above saved notes. These previews remain unsaved until you click them.

1. Copy text while Piper is running.
2. Open the capture panel with Command-1.
3. Click a card under Clipboard to save it.

The note saves to Inbox unless you selected another section. Its text remains unchanged. A failed save leaves the preview available.

Clipboard previews keep up to ten recent entries in memory. Repeated text appears once. Text already present in saved notes stays hidden.

Undo restores the note's preview while that entry remains in memory. Restarting Piper clears the preview history.

The observer reads plain text. It skips images, text larger than 500 KB, and clipboard items marked concealed, transient, or autogenerated.

## Enable Selection Capture

1. Open Piper Settings with Command-comma.
2. Select Open Accessibility Settings.
3. Enable Piper in the macOS Accessibility list.
4. Select text in another application.
5. Press and release Shift twice in quick succession.

Settings also offers Control-Option-Space. Piper checks permission changes every four seconds. It does not simulate Copy or replace the clipboard during selection capture.

Control-Option-Space registers with macOS. If another application reserves it, Piper reports the conflict. Choose double-Shift or release the conflicting shortcut.

The capture stores the source application. It also stores an HTTP or HTTPS document URL when the source application exposes one through Accessibility.

Compatibility depends on the source application's Accessibility support. Secure fields and empty selections do not create notes.

If selection capture fails, use the explicit fallback:

1. Copy the text in the source application.
2. Select Capture Clipboard from Piper's menu.

## Organize Notes

Command-K opens the section picker to change the destination for new captures. Entering `# Research` alone in the composer creates or selects that section.

Captured headings remain literal note text. The search field matches note text and section names. Cards show inline Markdown formatting.

To act on several notes:

1. Click a note to select it.
2. Command-click more notes, or Shift-click to select a range.
3. Select Copy as List, or open the ellipsis menu for more actions.

The circle on each card marks the note as done. Return opens the selected note for editing. Command-Return opens a separate editor.

The context menu provides Copy, Copy as List, completion, editing, merge, and move actions. Send to Wiki appears in the selection action menu.

Merge joins note bodies with blank lines. Copy as List creates numbered text and indents continuation lines. Undo restores the previous note operation.

Existing notes use Save Changes. The composer saves its unfinished draft automatically. Escape clears selection or search before it closes the panel.

Closing a separate editor or quitting Piper offers Save, Discard, and Cancel for changed captures. A failed save preserves the draft.

## Keyboard Reference

| Shortcut | Action |
| --- | --- |
| Command-1 | Open the capture panel |
| Command-2 | Open the Wiki browser |
| Command-comma | Open Settings |
| Command-K | Open the section picker |
| Command-F | Focus capture search |
| Command-N | Focus the composer |
| Return | Save the composer, or edit the selected note |
| Shift-Return | Insert a new line in the composer |
| Command-Return | Save text in an editor, or open the selected note in a separate window |
| Space | Complete or reopen selected notes |
| Up / Down | Select the previous or next note outside an editor |
| Shift-Up / Shift-Down | Extend the note selection |
| Command-A | Select all matching notes outside an editor |
| Escape | Clear selection, clear search, or close the panel |
| Command-W | Close the capture panel |
| Command-C | Copy selected notes |
| Command-Shift-C | Copy selected notes as a list |
| Command-Shift-M | Merge selected notes |
| Command-Z | Undo a note operation |
| Delete / Forward Delete | Delete selected notes |

Capture actions require the capture panel to be active with no sheet open. Text editing retains native copy and undo behavior.
